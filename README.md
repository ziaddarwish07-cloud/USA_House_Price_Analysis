USA House Price Analysis
An Exploratory Data Analysis (EDA) project uncovering the key factors driving residential property prices in the US.
Tech Stack:
• Python (Pandas, NumPy, Matplotlib, Seaborn)
• Google Colab
Highlights:
• Data Cleaning: Handled missing values, duplicates, and outliers.
• Analysis & Insights: Explored correlations between price, square footage, location, and property condition.
• Visualization: Created clear charts highlighting regional price trends.
